AETHERFALL MMO engine

A browser MMO engine with a 20Hz authoritative server, custom ECS and binary protocol. No game engine, no networking library.

Start AETHERFALLSee the world

World chunks and terrain

Chunks generate from a seed as you walk. The same terrain, hazards and landmarks exist on the server and in the client, so a step always lands where it looks.

Engine systems

Input arrives at 20Hz. The server resolves movement, combat and AI, then sends interest-culled snapshots at 10Hz. The client predicts your body and reconciles on the next ack.

Editor and collision export

Paint walls into a live scene, export the collision as JSON and the server reads it on the next boot. The level editor runs in the same client as the game.

Local quickstart commands

Node 22 and npm are enough. Build the workspaces, start the server in one terminal and the client in another, then open localhost:5173.

npm install npm run build --workspaces node server/dist/index.js # terminal 1, port 8081 npm run dev --workspace=@aetherfall/client # terminal 2, port 5173
