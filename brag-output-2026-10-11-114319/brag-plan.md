# Brag Plan: AETHERFALL

## What is this app?
A browser MMO engine built from scratch — authoritative 20Hz server, client prediction, binary protocol, Three.js isometric client. No engine, no networking library.

## The angle
A game-trailer edit for an engine: the joke/claim is the landing page's own line — "Just sockets, math, and pixels." Every number on screen is a measured number from the repo.

## Hook (first 2-3 seconds)
Black. "No engine." (beat) "No networking library." — then the AETHERFALL title slams in gold.

## Key moments (the middle)
- The isometric shrine screenshot framed as live gameplay: "a browser MMO, built socket by socket."
- The night-raid screenshot: boss telegraph ring + damage numbers — "4 bosses · server-sent telegraphs · finishers."
- Three stat cards landing on beats: "20 Hz authoritative" / "−93% bytes (binary v2)" / "300-bot soak · 0 errors."

## Outro / punchline
Editor screenshot + "ENTER THE FALL" + repo URL. Final line: "Runs in your browser. MIT."

## User flow worth showing
Join → swing → kill: simulated with the real HUD copy (join card "ENTER THE FALL", damage numbers, kill feed "☠ slain"). Centerpiece scenes show the game, not the landing page.

## Tone
- Preset: cinematic
- Creative direction: dark-fantasy game trailer, trailer-scale type, hard cuts
- Interpretation: big motion and big claims, but every claim is a repo number; restraint only in service of readability.

Sequential: two lines arrive one by one. Audio intent: tension, then release into Scene 2. Audio-coupled: hard hit under line 2. Music: bed starts low. Transition: hard cut → Scene 2 (beat-locked ~3.70s).

### Scene 2 — Title reveal — 3.8s (3.2–7.0)

### Scene 3 — Combat — 4.0s (7.0–11.0)

### Scene 4 — Numbers — 4.5s (11.0–15.5)
